# Renovate 43.272.6 structured-log fixture provenance

The repository lifecycle order and messages were captured from successful
Renovate workflow run `30604986686`, which executed the pinned
`ghcr.io/renovatebot/renovate:43.272.6` image across renovate-config, Roost,
and Groundwork. Names, timestamps, payloads, branch data, and provider output
were removed.

The timing object is anchored to Renovate tag `43.272.6`, immutable commit
`d2aa7e3e9465872580066db6f1fb6d842077e19a`: its repository worker logs
`getSplits()` at debug level, and that helper returns `splits` plus `total`.
The numeric values here are deliberately synthetic.

The warning, error, and fatal records are sanitized hostile scenarios added to
the captured lifecycle fixture. They contain no copied provider response,
credential, repository content, or raw error payload.
